# RescuePOV (レスキューPOV) 🚨

暗闇・遭難時・夜間災害時に、iPhoneの画面を頭上で左右に振ることで、数メートル〜数十メートル離れた救助者や探索ヘリに向けて「**HELP**」や「**SOS**」などの救難文字を残像として鮮明に結像させるiOSレスキューアプリケーションです。

---

## 🌟 主な特徴

### 1. Z軸角速度積分による「完全位置同期POV」
従来の単純な時間タイマー式ではなく、iPhoneのIMU（ジャイロセンサー）から得られるZ軸角速度（$\omega_z$）を100Hzでリアルタイム積分。腕の振りの空間座標（角度ストローク 0.0〜1.0）と描画を1対1で直結させています。
- **往路（右スイング）**: 空間位置に応じて極細LEDスリットを順次発光。
- **復路（左スイング）**: 網膜の像が重なってブレるのを防ぐため完全消灯。

### 2. 白飛び・文字潰れを根絶する「5x7精密ドットフォント」
高輝度残像表示で問題となる「文字間の光の重なりによる白残像」を解決するため、文字間に完全消灯の黒列（3列）と、縦ドット間のLEDギャップを確保した独自のビットマップジェネレータを搭載。遠方からでもシャープに結像します。

### 3. 実機スイング・ヒステリシス学習エンジン
人間の腕の振りは利き手（右手／左手）や往路・復路によって加速度・速度曲線（ヒステリシス曲線）が非対称になります。
- アプリ内に「10往復サンプリング計測」機能を搭載。
- ユーザー固有のスイング特性（角度レンジ、非対称比率）を記録・適応可能。

### 4. 遭難支援統合ツール
- **エマージェンシー・ホイッスル**: 最大音量のSOSモールス信号ブザー。
- **SOSトーチフラッシュ**: 背面LEDフラッシュライトの高速ストロボ点滅。
- **GPS現在地シェア**: ワンタップで緯度経度・住所を取得し救助要請文をコピー。

## 🛠 技術スタック

- **言語**: Swift 5.9+
- **UIフレームワーク**: SwiftUI
- **レンダリング**: UIKit / Core Animation (`CADisplayLink` 120Hz ProMotion対応)
- **モーション検出**: CoreMotion (`CMMotionManager` 100Hz IMUストリーミング)
- **位置情報**: CoreLocation
- **対応OS**: iOS 17.0+ (iPhone / iPad)

## 🚀 ビルド＆実行方法

1. リポジトリをクローン:
   ```bash
   git clone https://github.com/<your-username>/RescuePOV.git
   cd RescuePOV
   ```
2. Xcodeでプロジェクトを開く:
   ```bash
   open RescuePOV.xcodeproj
   ```
3. Xcodeの「Signing & Capabilities」で使用する Apple ID（Personal Team）を選択。
4. 実機（iPhone）を接続し、`Command + R` でビルド＆実行。
