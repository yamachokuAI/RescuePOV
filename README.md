# RescuePOV (レスキューPOV & パーティーPOV) 🚨 🎉

**【フェーズフリー（日常 ✕ 非常時）空中残像オプティクス・アプリケーション】**

日常の誕生日パーティー、ライブ・フェス、乾杯、夜間ランニングから、地震・豪雨・遭難時の救難要請まで、同じアプリ・同じ直感的操作で命を守る**フェーズフリー・テクノロジー**を搭載した次世代POVアプリです。

---

## 🌟 主な特徴 & 最新アップデート

### 1. 【フェーズフリー】日常（CELEBRATION）⇄ 非常時（RESCUE）ワンタップ切替
- **🎉 日常・パーティーモード**: 
  - 誕生日（HAPPY BIRTHDAY）、乾杯（CHEERS!）、推し活・愛（LOVE）、お祝い（CONGRATS）など。
  - パーティーマゼンタ、ネオンシアン、エメラルドグリーン、サンセットアンバーの美麗な発光。
- **🚨 非常時・遭難モード**: 
  - 救助要請（HELP）、国際救難（SOS）、叫び声（たすけて）、位置特定（ココ）、浸水孤立など。
  - レスキューホワイト、エマージェンシーレッド、ハイビズイエローの超高輝度発光。

### 2. 【疲労対策】振れ幅マルチモード（AI自動適応）
「1〜2分振ると腕が疲れて頭上に掲げられなくなる」「狭くて振るスペースがない」という課題を工学的に解決：
- **✋ 手首30cm浮き出しホログラムモード（アプリの真骨頂）**:
  - 腕を上げずに**手首のスナップ（左右約25〜35cm）だけ**を高速往復。
  - スリット幅を18pxに最適化し、空間狭域に文字を凝縮。空中に立体文字がホログラムのように鮮明に浮き出ます。
- **⚡️ 0cmゼロスイング（静止・全画面一文字ストロボ）モード**:
  - 体力が尽きて振れなくなった時や、狭所（瓦礫の下・車内・エレベーター）で振れない時。
  - スリットではなく**画面全体を使い、一文字ずつ「H」「E」「L」「P」を最大輝度ストロボ点滅**（0.36秒周期・暗転閃光効果）。
- **🤖 AI自動適応**:
  - 振りを止めて約1秒静止 → 自動で「0cm全画面ストロボ」へ移行。
  - 手首で小さく振り始める → 自動で「30cm浮き出しモード」へ適応。
  - 頭上で大きく振る → 自動で「ワイドモード」へシームレス展開。

### 3. 【多重防御】Shake to Undo（シェイクで取り消し）の完全根絶
- iPhoneを激しく振った際にiOS標準の「取り消し（Undo Typing）」アラートが画面を遮断する問題を、AppDelegate、UIWindowサブクラス、Appライフサイクルの多重レイヤーで完全無効化。

### 4. Z軸角速度積分による「完全位置同期POV」
- iPhoneのIMU（ジャイロセンサー）から得られるZ軸角速度を100Hzで積分。空間座標と描画を1対1直結。
- 往路・復路の両方向完全同期発光により、文字の反転・ブレを根絶。

### 5. 叫び声リアルタイム音声反映 (Shout-to-Text POV)
- 振りながら叫んだ声（HELP、たすけて、乾杯等）をマイクで拾い、リアルタイムに空中の文字へ即座に反映。

## 🛠 技術スタック

- **言語**: Swift 5.9+
- **UIフレームワーク**: SwiftUI
- **レンダリング**: UIKit / Core Animation (`CADisplayLink` 120Hz ProMotion対応)
- **モーション検出**: CoreMotion (`CMMotionManager` 100Hz IMUストリーミング)
- **位置情報**: CoreLocation
- **対応OS**: iOS 17.0+ (iPhone / iPad)

## 🚀 ビルド＆実行方法

1. リポジトリをクローン:
   ```bash
   git clone https://github.com/<your-username>/RescuePOV.git
   cd RescuePOV
   ```
2. Xcodeでプロジェクトを開く:
   ```bash
   open RescuePOV.xcodeproj
   ```
3. Xcodeの「Signing & Capabilities」で使用する Apple ID（Personal Team）を選択。
4. 実機（iPhone）を接続し、`Command + R` でビルド＆実行。
